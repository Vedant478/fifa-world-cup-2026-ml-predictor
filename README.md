# ⚽ FIFA World Cup 2026 ML Predictor

An end-to-end Machine Learning system that predicts the FIFA World Cup 2026 using historical international football data, Monte Carlo simulations, and an interactive web dashboard.

## 🚀 Live Demo

[Live Application](https://fifa-world-cup-2026-ml-predictor-production.up.railway.app/)

## 📊 Project Overview

This project predicts:

* Group-stage qualification probabilities
* Match outcome probabilities
* Knockout-stage progression
* Championship odds
* Most likely tournament bracket

using an ensemble of Machine Learning models trained on international football results.

## 🛠 Tech Stack

### Machine Learning

* Python
* Scikit-Learn
* Gradient Boosting Classifier
* Random Forest Classifier

### Data Processing

* Pandas
* NumPy

### Backend

* Flask
* Gunicorn

### Deployment

* Railway

### Simulation

* Monte Carlo Tournament Simulation

## 📈 Dataset

Historical international football matches:

* 49,000+ international fixtures
* FIFA rankings
* Official FIFA World Cup 2026 schedule

## 🎯 Features

### Group Stage

* Qualification probabilities
* Team rankings
* Group analysis

### Match Predictions

* Win / Draw / Loss probabilities
* Fixture-level predictions

### Knockout Stage

* Dynamic bracket generation
* Tournament progression

### Championship Odds

* World Cup winning probabilities
* Final appearance probabilities
* Semi-final probabilities
* Quarter-final probabilities
